# 미룬 일 몬스터 동네 (가칭)

할 일을 끝내며 주민을 만나고, 친구들과 마당·광장을 함께 사용하는 픽셀 아트 웹 게임입니다.
현재는 프로토타입이며 사용자와 Codex가 기획·개발·아트를 이어가고 있습니다.
기획과 상세 개발 기준은 [AGENTS.md](AGENTS.md)에 있습니다.

## 실행

Node.js 24 기준으로 확인했습니다.

```sh
npm ci
npm run dev
```

화면에서 방향키 또는 WASD로 이동합니다. 사물 가까이에서 E를 누르거나 그림을 클릭합니다.

- 수호나무: 방의 공동 할 일을 등록하고 완료합니다.
- 모닥불: 내 할 일을 골라 집중을 시작하거나 끝냅니다.
- 응원의 종: 응원을 보낼 친구를 고르고 응원 버튼을 누릅니다.
- T·C·B·R·G: 할 일·달력·도감·주민·방 창을 엽니다. Esc로 닫습니다.
- 첫 로그인에서 이름을 정한 다음 숲길·민트·라벤더 중 모습을 한 번 고릅니다. 선택은 계정에 저장되며, 다음 접속에도 같은 모습으로 시작합니다.
- 플레이어는 아래·위·옆 방향마다 따로 그린 4장의 걷기 그림을 재생합니다. 왼쪽은 옆 그림을 뒤집습니다.

개발 서버에서 `/?demo-room`으로 가짜 친구 방을 확인할 수 있습니다.
`/?demo-room=13`, `/?demo-room=50`으로 여러 마당 배치를 확인합니다. 가짜 방은 배포 버전에 포함되지 않습니다.

## 현재 상태와 다음 순서

| 영역 | 상태 |
| --- | --- |
| 할 일·집중·하루 계획·달력 | 구현, 규칙·저장소 자동 검사 |
| 주민 | 4종, 중복 친밀도·해금·마당 표시 구현 |
| 마당·광장 | 큰 집·나무·정원 배치, 방 인원에 따른 확장 |
| 광장 사물 | E·클릭, 집중·공동 할 일·응원 선택 연결 |
| 로그인·클라우드 저장·친구 방 | 코드와 DB 마이그레이션 준비, 실제 계정·다중 접속 검증은 다음 단계 |
| 주민 진화 그림 | ♥6 판정 구현, 시각 표현은 기획 미정 |

다음은 실제 계정으로 **로그인 → 할 일 등록 → 집중 → 완료 → 재접속 저장 복원**, 두 계정으로 방·공동 할 일·응원을 확인하는 단계입니다.
가짜 방에서 동작한 결과를 실제 서비스 검증으로 간주하지 않습니다.

## Supabase 연결

연결 값이 없으면 내 데이터는 이 브라우저에 저장됩니다.
클라우드 기능은 [.env.example](.env.example)의 항목을 `.env.local` 또는 배포 환경에 설정하고,
[0001_init.sql](supabase/migrations/0001_init.sql)과 [0002_room_slots.sql](supabase/migrations/0002_room_slots.sql)을 순서대로 적용합니다.
카카오 로그인과 리다이렉트 주소는 Supabase·카카오 설정에서 연결합니다. 비밀 값은 저장소에 올리지 않습니다.
