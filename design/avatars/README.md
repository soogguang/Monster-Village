# 플레이어 외형과 걷기

숲길(갈색 머리·청록 목도리), 민트(민트 머리·초록 멜빵옷), 라벤더(보라 단발·노란 카디건) 3종입니다.
앱의 **내 모습(V)**에서 선택하며, 할 일·주민과 함께 `avatarId`를 저장합니다. 주민 도감과 별개입니다.

- [외형·방향 미리보기](avatars-preview.png)
- [다리 움직임 GIF](walking-preview.gif)
- `model-sheet.png`: 기존 플레이어를 참고해서 생성한 정면·뒷모습·오른쪽 원화
- `build_avatars.py`: Pillow로 64×72 내보내기, 색 정리, 팔·다리 분리와 걷기 프레임 조립

```sh
python design/avatars/build_avatars.py
```

기존 `player-front.png`, `player-back.png`는 그대로 두고 숲길의 정지 그림으로 사용합니다.
걷기는 왼발·오른발을 각각 움직인 4프레임이며, 옆모습에서는 앞뒤 다리를 나누어 그립니다.
캐릭터 전체를 통째로 흔드는 방식만으로 다리 움직임을 대신하지 않습니다.

게임용 파일은 `public/assets/characters/avatars/`에 있습니다.

| 파일 | 내용 |
| --- | --- |
| `{id}-walk.png` | 320×216 스프라이트 시트, 칸당 64×72 |
| `{id}-down.png` | 아래를 보는 정지 그림 |
| `{id}-up.png` | 위를 보는 정지 그림 |
| `{id}-side.png` | 오른쪽을 보는 정지 그림 |

시트는 5열×3행입니다. 행은 아래·위·옆 순서, 열은 정지·왼발 디딤·다음 발 준비·오른발 디딤·다음 발 준비 순서입니다.
12개의 걷기 프레임을 초당 8프레임으로 반복하고, 멈추면 그 방향의 정지 칸으로 돌아갑니다. 왼쪽은 옆 그림을 뒤집습니다.
발의 위치를 기준으로 충돌과 깊이를 유지합니다. 시트의 각 칸 마지막 행 y=71은 투명하며 알파는 0/255입니다.
키를 놓거나 창이 열리거나 벽에 막히면 걸음을 멈춥니다.
