# 펠트토끼 눈 정리

사용자 요청으로 정면·점프 그림의 가운데 흰 점을 없애고, 강아지·고양이처럼 작은 갈색 눈의 **왼쪽 위**에 따뜻한 흰 반짝임을 넣었습니다.
귀·펠트 색상·몸·잠든 표정은 기존 그림을 유지합니다.

[비교 미리보기](eye-preview.png)는 게임에서 사용하는 PNG 자체를 4배 정수 확대했고 아래에 실제 크기도 넣었습니다. 왼쪽부터 강아지·고양이·토끼 정면·토끼 점프입니다.

```sh
python design/rabbit/adjust_eyes.py
```

Pillow로 64×72 원본의 눈 영역만 정리하는 작업입니다. 다시 실행해도 결과가 같으며, 게임용 PNG는 `public/assets/characters/`에 있습니다.
