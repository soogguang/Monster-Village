# 새 주민 초안 4종

[기본형·특별형 비교](preview.png)에는 4배 정수 확대와 실제 1배 크기가 함께 있습니다.
검토용 초안이며 게임의 주민 목록과 해금 조건에는 등록하지 않았습니다. 특별형을 ♥6 진화에 사용할지도 아직 확정하지 않았습니다.

| 후보 | 계열 제안 | 기본 모습 → 특별한 모습 |
| --- | --- | --- |
| 별가시 고슴도치 | 희귀 새싹 | 반짝이는 조각 모으기 → 등에 별꽃 피우기 |
| 이불등 거북 | 꾸벅이 | 작은 이불을 얹은 등껍질 → 포근한 조각 이불 등껍질 |
| 찻잔 수달 | 꾸벅이 | 따뜻한 찻잔 안기 → 큰 찻잔 안에서 쉬기 |
| 낙서 너구리 | 말썽 | 색연필 모으기 → 알록달록한 붓 꼬리 |

- `png/`: 실제 **64×72 RGBA PNG 8장**. `*-base.png`는 기본형, `*-special.png`는 특별형입니다.
- 발밑 y=70, 마지막 행 y=71은 투명합니다. 알파는 0/255, 한 쌍당 공통 팔레트는 최대 24색입니다.
- `sources/`: 64칸에서 읽히는 실루엣과 큰 색 덩어리를 목표로 생성한 확대 원화입니다. 실제 게임 칸은 `png/`를 기준으로 검토합니다.
- `drafts.json`: 검토용 파일 목록입니다. 게임의 `catalog.json`과 별개입니다.

Pillow가 설치된 환경에서 다음 명령으로 원화를 픽셀 PNG로 내보냅니다.

```sh
python design/resident-prototypes/build_prototypes.py
```

원화의 두 모습을 같은 축척으로 줄이고, 가장자리 투명도를 정리하고, 팔레트를 통일합니다. `/workspace/exports/resident-concepts/`에 PNG 묶음 ZIP과 비교용 HTML도 만듭니다. HTML의 `main`을 브라우저에서 1배로 캡처한 것이 `preview.png`입니다.
