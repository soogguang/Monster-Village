# 캐릭터 이미지: 만두·강아지·솜털고양이·펠트토끼

만두는 **음식을 먹으면 몸통 양옆의 둥근 볼주머니에 차곡차곡 저장해요.**
몸통은 가로로 넓적하며, 음식이 찬 모습에서는 다람쥐처럼 주머니가 얼굴과 같은 높이에서
몸통 양옆으로 돌출됩니다. 볼주머니는 팔다리가 아닙니다.

강아지는 **땅파기를 좋아해요.** 접힌 귀, 동그란 배 무늬, 짧은 팔다리와 꼬리는
사용자가 그린 정면·뒷모습·땅파기 스케치를 바탕으로 만들었습니다.
강아지 이름은 임시로 `강아지`이며, 털과 귀의 색은 크림·갈색 시안입니다.

솜털고양이는 **민들레처럼 쉬는 걸 좋아해요.** 삼각 귀, 솜털 윤곽, 긴 꼬리와
밝은 배 무늬를 유지하고, 쉬는 모습에서는 고양이 머리가 민들레 꽃송이가 됩니다.

펠트토끼는 **긴 펠트 귀를 흔들며 폴짝폴짝 뛰는 걸 좋아해요.**
몸은 연분홍, 몸통의 천 패치는 회민트색입니다. 양쪽 귀 모두 연보라와
부드러운 버터 노랑 조각 천이 섞이고, 짙은 갈색 봉제선이 보입니다.
사용자가 제공한 색상 스케치를 반영한 승인된 디자인입니다.

사용자가 그린 스케치와 승인한 디자인을 바탕으로 만들었습니다.

모든 파일은 **64×72픽셀 RGBA PNG**입니다. 투명도는 0 또는 255이며,
가로로 가운데 정렬하고 바닥을 y=70에 맞췄습니다. 마지막 행(y=71)은 투명합니다.
Phaser에서는 원본 크기로 불러오고 최신 카메라 배율 **1배·2배**를 사용하세요.
확대 미리보기 이미지는 게임 텍스처가 아닙니다.
토끼 점프 그림도 같은 바닥 위치로 정렬했습니다. 공중으로 올라가는 이동은 화면 코드에서 처리하세요.

32픽셀 파일을 두 배로 늘리는 대신, 큰 원본과 복원된 격자에서 다시 정리했습니다.
강아지는 `design/puppy-base/`의 64×72 바탕에서 기하와 얼굴을 보존하고 비슷한
크림색을 통합했습니다. 고양이는 승인된 큰 원본에서 64픽셀 격자로 변환해 눈·입·털을 살렸습니다.
만두도 승인된 넓적한 큰 원본에서 다시 변환해 눈과 입의 디테일을 살렸으며,
넓적한 비율과 얼굴 높이의 볼주머니를 유지합니다.
서 있는 모습, 땅파기·수면·민들레 형태는 자세에 따라 높이가 다릅니다.

네 캐릭터는 기본 일반 새싹(`sprout`, `rare: false`, `unlock: null`)으로 등록했습니다.
현재 렌더러는 `image`를 불러옵니다. `sleepImage`와 먹기·볼 저장 상태의
이미지 전환, 뒷모습·땅파기·민들레 변신·점프·착지는 Claude 담당 화면 코드에서 연결해야 합니다.
PNG 16개는 주민 4종의 서로 다른 모습이며 별도 주민 16종이 아닙니다.
