# 캐릭터 이미지: 만두와 강아지

만두는 **음식을 먹으면 몸통 양옆의 둥근 볼주머니에 차곡차곡 저장해요.**
몸통은 가로로 넓적하며, 음식이 찬 모습에서는 다람쥐처럼 주머니가 얼굴과 같은 높이에서
몸통 양옆으로 돌출됩니다. 볼주머니는 팔다리가 아닙니다.

강아지는 **땅파기를 좋아해요.** 접힌 귀, 동그란 배 무늬, 짧은 팔다리와 꼬리는
사용자가 그린 정면·뒷모습·땅파기 스케치를 바탕으로 만들었습니다.
강아지 이름은 임시로 `강아지`이며, 털과 귀의 색은 크림·갈색 시안입니다.

사용자가 그린 스케치와 승인한 첫 시안을 바탕으로 만들었습니다.

| 파일 | 모습 | 용도 |
| --- | --- | --- |
| `sprout-mandu.png` | 기본 정면 | `catalog.json`의 `image` |
| `sprout-mandu-eat.png` | 딸기를 먹는 모습 | 먹기 동작에 연결할 추가 이미지 |
| `sprout-mandu-full.png` | 양 볼에 음식을 저장한 모습 | 볼이 찬 상태에 연결할 추가 이미지 |
| `sprout-mandu-sleep.png` | 볼에 음식을 저장한 채 잠든 모습 | `catalog.json`의 `sleepImage` |
| `sprout-puppy.png` | 강아지 정면 | `catalog.json`의 `image` |
| `sprout-puppy-back.png` | 강아지 뒷모습 | 뒤로 걷는 모습에 연결할 추가 이미지 |
| `sprout-puppy-dig.png` | 앞발로 땅을 파는 모습 | 성격을 표현하는 동작에 연결할 추가 이미지 |
| `sprout-puppy-sleep.png` | 앉아서 잠든 모습 | `catalog.json`의 `sleepImage` |

모든 파일은 **32×32픽셀 RGBA PNG**입니다. 투명도는 0 또는 255이며,
공유 팔레트를 사용합니다. 만두 그림의 높이는 18픽셀이며 주름과 얼굴의 위치를 맞췄습니다.
볼이 찬 모습에서는 얼굴이 있는 행(y=19~25)에서만 양옆으로 넓어지고, 머리 윗부분과
몸통 아래쪽 모양은 기본 모습과 같습니다. 강아지는 모든 동작에서 같은 축척을 사용하며,
땅파기와 잠자는 모습은 자세에 따라 높이가 낮아집니다.

그림의 바닥은 y=30이며 마지막 행(y=31)은 투명합니다.
Phaser에서는 원본 크기로 불러오고 기존 카메라 배율 2배·3배를 사용하세요.
확대 이미지를 게임 텍스처로 사용하지 마세요.

두 캐릭터는 우선 기본 일반 새싹(`sprout`, `rare: false`, `unlock: null`)으로 등록했습니다.
현재 렌더러는 `image`를 불러옵니다. `sleepImage`와 먹기·볼 저장 상태의
이미지 전환, 강아지의 뒷모습·땅파기는 Claude 담당 화면 코드에서 연결해야 합니다.
PNG 8개는 주민 2종의 서로 다른 모습이며 별도 주민 8종이 아닙니다.
