# 강아지 캐릭터 이미지

강아지는 **땅파기를 좋아해요.** 접힌 귀, 동그란 배 무늬, 짧은 팔다리와 꼬리는
사용자가 그린 정면·뒷모습·땅파기 스케치를 바탕으로 만들었습니다.
이름은 임시로 `강아지`이며, 크림색 털과 갈색 귀를 사용합니다.

| 파일 | 모습 | 용도 |
| --- | --- | --- |
| `sprout-puppy.png` | 정면 | `catalog.json`의 `image` |
| `sprout-puppy-back.png` | 뒷모습 | 뒤로 걷는 모습에 연결할 추가 이미지 |
| `sprout-puppy-dig.png` | 앞발로 땅을 파는 모습 | 성격을 표현하는 동작에 연결할 추가 이미지 |
| `sprout-puppy-sleep.png` | 앉아서 잠든 모습 | `catalog.json`의 `sleepImage` |

모든 파일은 **32×32픽셀 RGBA PNG**이고 투명도는 0 또는 255입니다.
공유 팔레트와 같은 축척을 사용하며, 땅파기와 잠자는 모습은 자세에 따라 높이가 낮아집니다.
그림의 바닥은 y=30이며 마지막 행(y=31)은 투명합니다.
Phaser에서는 원본 크기로 불러오고 기존 카메라 배율 2배·3배를 사용하세요.

기본 일반 새싹(`sprout`, `rare: false`, `unlock: null`)으로 등록했습니다.
현재 렌더러는 `image`를 불러옵니다. 수면·뒷모습·땅파기 이미지로 전환하는 동작은
Claude 담당 화면 코드에서 연결해야 합니다. 네 그림은 주민 한 종의 서로 다른 모습입니다.
