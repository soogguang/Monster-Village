# 캐릭터 이미지: 만두·강아지·솜털고양이·펠트토끼

만두는 **음식을 먹으면 몸통 양옆의 둥근 볼주머니에 차곡차곡 저장해요.**
몸통은 가로로 넓적하며, 음식이 찬 모습에서는 다람쥐처럼 주머니가 얼굴과 같은 높이에서
몸통 양옆으로 돌출됩니다. 볼주머니는 팔다리가 아닙니다.

강아지는 **땅파기를 좋아해요.** 두 발로 서고, 갈색으로 접힌 귀와 크림색 털, 짧게 말린 꼬리가 있어요.
2026-11-10 사용자가 준 그림 4장(정면·뒷모습·땅파기·앉기)을 1칸 = 1픽셀로 옮겼습니다. 정면 높이 52픽셀이고,
ω 입과 땅파기의 진한 눈썹이 포인트이며, 눈을 뜬 그림은 눈마다 흰 점 1개를 남겼습니다.

솜털고양이는 **민들레처럼 쉬는 걸 좋아해요.** 삼각 귀, 솜털 윤곽, 긴 꼬리와
밝은 배 무늬를 유지하고, 쉬는 모습에서는 고양이 머리가 민들레 꽃송이가 됩니다.

펠트토끼는 **긴 펠트 귀를 흔들며 폴짝폴짝 뛰는 걸 좋아해요.**
연분홍 몸에 회민트색 패치를 두고, 귀에는 연보라·버터 노랑·딸기빛·크림색 사각 천을 섞었습니다.
네 자세에 크림색 박음질을 넣었고, 정면과 점프는 작은 갈색 눈과 `ω` 모양 입을 씁니다.
